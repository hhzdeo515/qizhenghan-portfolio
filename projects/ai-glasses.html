AI 眼镜智能助手

让多模态能力，
进入镜片视野。

把会议纪要和拍照解题放进镜片，用戒指、键盘或触控完成选择与确认。为小屏与有限操作，设计清楚的输入、处理和反馈。

PRODUCT FOCUS会议纪要 / 拍照解题 / 眼镜与戒指协同
查看 GitHub
01

拍下问题，逐题处理

识别单题、多题与共用材料，连接资料检索、计算工具和原图复核，保留证据不足时的补拍与退出路径。

02

听见内容，核对纪要

录音或导入音频，经转写、纪要生成与原文核验后归档；异步任务保留进度和检查点。

03

有限输入，清楚操作

在镜片内选择场景和阅读结果，用虚拟戒指滑动、确认与返回，提前检验硬件形态带来的操作限制。

技术与工作流DETAILS +

Next.js / React / Flask / LangGraph。多模态处理、资料检索与工具调用组成场景工作流，任务支持持久化和检查点恢复。

支持原版与 JEV 决策流程切换，参考资料与题解、会议记录可保留历史；写作和面试入口可处理用户草稿及实际回答。

当前能力边界DETAILS +

眼镜、戒指及传输链路为浏览器模拟，真实设备接入尚未实现。摄像头、麦克风使用当前设备，模型请求需配置服务凭据。

解题与会议结果仍需用户核验。开发集复测和模拟回归不能证明任意新题准确率或设备验收结果；当前没有独立账号和多租户鉴权。
